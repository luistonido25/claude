Coming from n8n?

This track assumes you may already know an automation tool (the GHL track here teaches n8n). Make.com is the same ideas with different names and two real differences: per-operation pricing and iterators/aggregators instead of automatic item looping. The fundamentals days are fast and drill-based — don't skip them, the vocabulary shift matters in interviews.

  • n8n workflow → Make scenario
  • n8n node → Make module · n8n credentials → Make connections
  • n8n execution → Make run, billed per operation (every module cycle counts)
  • n8n expressions → Make mapping panel + functions
  • n8n loops over items automatically → Make needs explicit iterators (split) and aggregators (join)
