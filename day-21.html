Session 1 — Morning audit + workflow inventory

≈ 2 hours

Before you package the week's work, you audit it the way an agency lead audits a build before client handoff: every workflow opened, verified published, consistently named, and logged in an inventory document. This document itself becomes portfolio material — it screams "professional".

Session 2 — Build the snapshot: "Dental Growth Suite v1"

≈ 1.5 hours

A Snapshot is a saved template of a sub-account's assets — pipelines, workflows, calendars, forms, funnels, custom fields/values, and more — that can be loaded into any other sub-account in one click. Agencies use snapshots to onboard new clients in minutes instead of weeks, and they SELL them as products ($97–$997 is a normal range). You're about to turn this week's work into one.

Session 3 — Prove it: load into a throwaway sub-account

≈ 1.5 hours

An untested snapshot is a rumor. The professional move — and the exact procedure for onboarding a real client — is: create account → load snapshot → verify assets → fix what snapshots can't carry. You'll run the whole drill on a throwaway.

Session 4 — Package Portfolio #9 + close out Week 3

≈ 1–1.5 hours

Portfolio #9 is different from #5–#8: the artifact isn't a workflow, it's a PRODUCT. So the documentation is a product one-pager and the Loom is a sales demo, not a build walkthrough.
