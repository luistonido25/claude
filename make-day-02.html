Session 1 — The mapping panel, inside out

≈ 1 hour

Everything you typed into fields yesterday goes through the mapping panel — the popup that appears when you click into any module field. It has two halves: mappable items (the colored chips from earlier modules) and a function library organized in tabs. In n8n you wrote {{ $json.name }} expressions; in Make you click chips and wrap them in functions. Same power, different muscle memory — today builds that muscle.

Session 2 — Function categories with Set Variable + Compose

≈ 1.5 hours

You'll practice functions in a scratch scenario using two free utility modules: Tools > Set variable (create a value) and Tools > Compose a string (display a result). This costs 2 operations per test run — the cheapest possible practice rig.

Session 3 — THE BIG ONE: iterators and aggregators

≈ 2 hours

This is the concept that separates Make users from Make professionals. n8n loops over items invisibly; Make makes flow control explicit. An iterator splits one bundle containing an array into many bundles (1 → N). An aggregator collects many bundles back into one (N → 1). Every module between an iterator and an aggregator runs once per bundle — and bills one operation per run. Master this and you control both correctness and cost.

Session 4 — JSON module + six timed drills

≈ 1.5–2 hours

One more tool for the belt — parsing raw JSON strings — then the drill block. Set a visible timer for every drill. Passing time is generous on purpose: the point is doing it without notes.

💡 The interview answer

When someone asks "what's the difference between Make and other tools?", the professional answer is: explicit flow control. "In Make I decide exactly where bundles multiply and where they collapse, so I can put a filter or aggregator exactly where it saves operations."
